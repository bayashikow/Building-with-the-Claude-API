## 1. このレッスンの目的
このセクションで作る題材(リマインダー機能)と、必要な3つのツールを理解する。

## 2. プロジェクトの目標(ページ)
- Claude に、将来の日付のリマインダーを設定する方法を教える。
- 目標: 「診察の予約のリマインダーを設定して。来週の木曜日です」と伝えると、Claude が「了解しました、リマインドします」と応答し、実際にリマインダーが設定されること。
- 簡単に聞こえるが、カスタムツールで解決すべき課題がいくつか隠れている。

## 3. なぜ難しいか: Claude の限界3つ(ページ)
Claude は現在の日付を知っているが、次の3つの問題がある。
| 限界 | 内容 |
|---|---|
| 時間認識の限界 | 現在の日付は知っていても、正確な時刻は分からない場合がある |
| 日付計算の問題 | 時間ベースの加算、特に多くの日数先の計算をうまく処理できないことがある |
| リマインダー機能の欠如 | 設定方法を知らない。そのための組み込みの仕組みがない |

- それぞれが、Claude が自然にできることと、リマインダーシステムに必要なことの間のギャップ。ツールがそのギャップを埋める。

## 4. 必要な3つのツール(ページ)
| ツール | 役割 | 対応する限界 |
|---|---|---|
| 現在の日時を取得する | 現在の日付と時刻を正確に知る | 時間認識の限界 |
| 日時に期間を加算する | 日時の加算を確実に行う | 日付計算の問題 |
| リマインダーを設定する | システム内で、実際にリマインダーを設定する | リマインダー機能の欠如 |

- (対応する限界の列は、ページの「それぞれの課題に対応するために、3つの個別のツールを作成する」という記述を、私が表に整理したもの。)
- 実装は、最もシンプルなものから一つずつ。より複雑な機能の前に、ツール呼び出しの仕組みを理解するため。
- 完成すると、Claude はこれらのツールを組み合わせて正確な時刻を計算し、リマインダーを設定する。「1週間後にリマインドして」のような自然言語のリクエストを処理できる。

## 5. 重要な原則(ページ)
モデルに制限がある場合、プロンプトでその制限を回避しようとするのではなく、**ツールを通じて能力を拡張する**。

## 質疑(学習中の確認)
範囲: このレッスン(L21)の内容。

### 質問1: 日付計算を確実にするための設計はどれか
出題: 「来月の第2火曜日にリマインドして」と頼む機能で、日付の計算を確実に正しくしたいとき、最も適切な設計は。
- A: 「日付は慎重に計算してください」と、プロンプトで強く指示する。
- B: 日付計算を行う関数をツールとして用意し、Claude にはそのツールを呼ぶ判断をさせる。
- C: 計算例を10個プロンプトに入れて、Claude に正しい計算を学ばせる。
- D: Claude の計算結果を、毎回、人が確認する運用にする。
- YUTAの回答: B(理由の記載はなかった)
- 評価: 正解。
  - B が正しい理由: 日付計算は、決まった規則で確実に答えが出る処理。コードに任せれば、毎回同じ結果になる。Claude には、「どのツールを、どの引数で呼ぶか」の判断だけをさせる。ページの「ツールで能力を拡張する」にあたる。
  - A: 指示を強めても、モデルの計算能力は変わらない。「慎重に」は、新しい情報を与えない(L19 の問題と同じ)。
  - C: 例を増やすと精度は上がりうるが、確実にはならない。「第2火曜日」のように条件が複雑になるほど、例にない入力で誤るおそれが残る。確実さが必要な処理に、確率的な方法で対処する形になる。
  - D: 毎回人が確認すると、自動化の意味が薄れる。誤りを防ぐのではなく、見つける手段で、コストも毎回かかる。補助的な運用としてはありえるが、第一選択ではない。
- 補足: B の設計でも、Claude が「来月の第2火曜日」を、ツールに渡せる形に変換する必要がある。ここで誤る可能性は残る。ツールの引数の設計(入力を曖昧さの少ない形にする)は、後続のレッスン(ツールスキーマ)で扱われると思われる(未確認)。

## 【補足】ページ外の内容(私の整理)
- この原則は、設計の判断基準として重要。確実に正しくあるべき処理(日付計算、時刻の取得)は、確率的なモデルに任せず、決まった結果を返すコードに任せる。L13 の「機械的に確定できる事柄を、確率的なモデルに任せるのは割に合わない」と同じ考え方。
- 設計書で言えば、計算ロジックをモデルの外の部品に切り出し、モデルには「どの部品を、どの引数で呼ぶか」を判断させる分担。
- 「現在の日時を取得する」ツールがあれば、Claude が今日の日付を取り違えることも防げる。3つのツールが別々の限界に対応しているのは、そのため。
- ページの3つの限界の程度は、モデルや時期で異なる可能性がある(確かでない)。ここでは、題材として受け取ればよい。
- 試験ガイドとの関係: ツール使用はガイドの複数の箇所に関係するが(L20 のノート参照)、このレッスン自体を直接扱う項目は、確認していない。
