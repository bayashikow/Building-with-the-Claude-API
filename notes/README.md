## ルール
- 1レッスン = 1ファイル。ファイル名は `L<番号>_<レッスンのslug>.md`。
- セクションごとにフォルダを分ける(`01_...`、`02_...`)。フォルダ名はコースのセクション順。
- 本文の要約と、ページ外の補足は分ける。補足には【補足】と書く。
- 先頭に、出典URL・読んだ日・凡例を書く。
